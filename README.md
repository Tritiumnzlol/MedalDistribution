# Medal Distribution

<img width="1301" height="732" alt="bar5" src="https://github.com/user-attachments/assets/1650d584-4d7e-4ee3-938f-30a271dbb4ea" />

Medal Distribution is a plugin for Trackmania that gives you a quick visual overview of how the playerbase is distributed across a track’s medals.

Some maps are easier with many AT times, so the green part of the bar is larger, and some ATs are harder with it being smaller. 

Your Personal Best can be displayed along the bar, to see where you sit relative to everyone else on the track.

**Features:**
* Visual Author / Gold / Silver / Bronze / No Medal distribution
* Works automatically with the currently loaded timed map
* Horizontal and vertical display modes
* Medal labels aligned with their actual position in the distribution
* Configurable label placement; Above or below for horizontal bars, Left or right for vertical bars
* Personal Best marker displayed directly on the distribution
* PB leaderboard percentile
* Approximate map difficulty rating
* Blended/fuzzy medal boundaries when precise ranks are unavailable
* ? indicators instead of misleading zero-percent medal groups
* Adjustable medal colours, bar opacity, overlay background opacity
* Draggable
* Optional automatic hiding while the car is moving with a configurable movement threshold
* Optional map name, difficulty, percentages, PB, and player-count display
* Leaderboard caching and retry handling
* Debug logging for troubleshooting leaderboard results
